# AgeLens V1.0.0

Release date: 22 July 2026

AgeLens V1 provides a governed, reproducible implementation of Phenotypic Age
for NHANES 2015–2018.

## Included

- public-safe canonical notebooks;
- final configuration and governance records;
- laboratory harmonization and validation documentation;
- survey-weighted aggregate tables and figures;
- all-cause mortality model outputs and diagnostics;
- public-release safety and integrity checks.

## Not distributed

- raw NHANES source files;
- participant-level or interim datasets;
- mortality source records;
- unpublished manuscript and supplementary manuscript;
- cause-specific mortality outputs.
